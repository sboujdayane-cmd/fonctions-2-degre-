2. Comprendre les notions

Fonction du second degré

Une fonction du second degré s'écrit :

f(x)=ax²+bx+c

avec a ≠ 0.

Sa représentation graphique est une parabole.

Sens d'ouverture

Si a>0, la parabole est ouverte vers le haut.

Si a<0, elle est ouverte vers le bas.

Plus |a| est grand, plus la parabole est resserrée.

Sommet

L'abscisse du sommet est :

xS = −b/(2a)

Puis :

yS = f(xS)
Axe de symétrie

La parabole est symétrique par rapport à la droite :

x = xS

Ainsi, si deux abscisses sont à la même distance de xS, leurs images sont égales.

Discriminant
Δ = b² − 4ac
  • Δ>0 : deux solutions réelles ;
  • Δ=0 : une solution réelle double ;
  • Δ<0 : aucune solution réelle.
Zéros

Les zéros sont les solutions de :

ax²+bx+c=0

Graphiquement, ce sont les abscisses des points où la parabole coupe l'axe des x.

Question rapide

Une parabole a pour sommet S(3 ; −2). Quelle est l'équation de son axe de symétrie ?
