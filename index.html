3. Synthèse de théorie

Cette page rassemble les formules et les raisonnements essentiels à connaître.
1. Forme générale
f(x)=ax²+bx+c

Pour être du second degré, il faut impérativement :

a ≠ 0

Le graphique est une parabole.

2. Rôle de a

Le signe de a détermine l'ouverture.

  • a>0 : ouverture vers le haut ;
  • a<0 : ouverture vers le bas.

Plus |a| est grand, plus la parabole est resserrée.

3. Ordonnée à l'origine
f(0)=c

La parabole coupe l'axe des ordonnées au point :

(0 ; c)
4. Sommet
xS = −b/(2a)

Puis :

yS=f(xS)

Le sommet est S(xS ; yS).

5. Axe de symétrie
x=xS

Si deux abscisses sont à égale distance de xS, leurs images sont identiques.

6. Discriminant
Δ=b²−4ac
  • Δ>0 : deux solutions réelles ;
  • Δ=0 : une solution réelle double ;
  • Δ<0 : aucune solution réelle.
7. Formule des racines

Si Δ>0 :

x₁=(-b−√Δ)/(2a)
x₂=(-b+√Δ)/(2a)

Si Δ=0 :

x₀=−b/(2a)
8. Interprétation graphique

Les solutions de :

f(x)=0

sont les abscisses des points d'intersection entre la parabole et l'axe des x.

9. Maximum ou minimum

Si a>0, le sommet correspond au minimum.

Si a<0, le sommet correspond au maximum.

Dans un problème, il faut toujours interpréter ce résultat.

Méthode complète

  1. Identifier a, b et c.
  2. Observer le signe de a.
  3. Calculer le sommet si nécessaire.
  4. Calculer Δ pour étudier les zéros.
  5. Déterminer les solutions.
  6. Faire le lien avec le graphique.
  7. Interpréter dans le contexte du problème.
