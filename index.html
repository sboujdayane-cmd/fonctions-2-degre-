📐 Fonction du 2e degré

Clique pour voir…

f(x) = ax2 + bx + c

avec a ≠ 0

Exemple : f(x) = 2x2 − 3x + 1

🎯 Sommet

Clique pour voir…

xS = −b / (2a)

yS = f(xS)

Le sommet est S(xS ; yS).

⚫ Zéros

Clique pour voir…

Les zéros sont les solutions de ax2 + bx + c = 0.

Δ = b2 − 4ac

  • Δ > 0 : deux solutions réelles
  • Δ = 0 : une solution réelle double
  • Δ < 0 : aucune solution réelle

🏀 Tir au basket

La hauteur du ballon est modélisée par :

h(t) = −5t2 + 10t + 2

h est exprimée en mètres et t en secondes.

💰 Bénéfice

Une entreprise modélise son bénéfice par :

B(x) = −2x2 + 20x − 30

x représente des centaines d'objets.

🌍 Problèmes concrets

🚀 Fusée

La hauteur d'une fusée miniature est modélisée par :

h(t) = −5t2 + 40t

📦 Boîte optimale

Le volume d'une boîte est donné par :

V(x) = x(30 − 2x)2

Dans ce modèle, 0 < x < 15.
